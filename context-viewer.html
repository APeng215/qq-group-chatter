神奈 · Context 查看器

本地查看提示词模板与真实 LLM 请求。选择项目目录后每 2 秒刷新，无需启动服务，文件内容不会上传。

请用 Edge / Chrome 打开，选择 qq-group-chatter 项目目录。首次选择需要浏览器授权只读访问。

真实调用来自 logs/llm-traces.jsonl（可另选自定义路径）。无新请求时显示上次调用；模板修改需重启机器人，运行中进程可能仍使用旧模板。其他浏览器可导入快照，快照不会自动更新。

项目目录会保存在当前浏览器，下次自动恢复。若读取权限过期，只需点击“恢复目录访问”，无需重新选目录。清除浏览器数据、更换浏览器或移动本页面后可能需要重新选择。
